# 공용 도면

여기에 담아 둔 도면은 배포된 앱의 툴바 **「공용 도면」** 목록에 나타납니다.
서버가 필요 없습니다 — git push 하면 Vercel 이 배포하고, 주소에 들어온 사람은
누구나 골라 씁니다.

## 도면 추가하기

1. 앱에서 **「내보내기」** — `egis-layout-YYYY-MM-DD.json` 이 받아집니다
2. 그 파일을 이 폴더에 넣습니다 (이름은 알아보기 쉽게 바꿔도 됩니다)
3. `index.json` 의 `layouts` 에 한 줄 적습니다

```json
{ "id": "line-a", "name": "A 라인 · 조립 2단", "note": "카트 3대로 도는 배치", "file": "line-a.json" }
```

| 칸 | 뜻 |
|---|---|
| `id` | 안 겹치는 짧은 이름. 없으면 순번으로 채웁니다 |
| `name` | 목록에 뜨는 이름. 없으면 파일 이름을 씁니다 |
| `note` | 한 줄 설명 — **이름에 다 넣으려 들면 이름이 문장이 됩니다** |
| `file` | 이 폴더 안의 파일 이름. 바깥 주소(`https://…`)나 `../` 는 무시됩니다 |

4. `git push` — Vercel 이 배포하면 끝입니다

## 주의

- 이 폴더는 **저장소에 그대로 들어갑니다.** 저장소가 공개면 도면도 공개입니다.
- 목록 파일이 없거나 비어 있으면 「공용 도면」 버튼 자체가 안 나옵니다.
  갤러리를 안 쓰는 배포에서 빈 목록이 떠 있으면 고장처럼 보이기 때문입니다.
